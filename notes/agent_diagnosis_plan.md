# Agent 轨迹诊断方向：设计文档（Phase 0-2）

> 定位：用 IIGC 梯度幸存框架诊断 coding agent 训练停滞。
> 不是行为层诊断（TRAJEVAL/TrajAudit/Coherence Collapse/RAGEN 已占），
> 而是补"梯度信号物理"层：隐藏条件导致的静默相消、可预测闭式、κ 测量。
> 状态：2026-08-26 立项，排在 Paper 1 之后。
> 查新：2026-08-26（见下 §7）。

---

## 1. 一句话主张（候选）

> 在 coding agent 的轨迹级训练数据中，当轨迹按隐藏条件（解法类型、仓库约定、
> 测试风格）分层且条件间最优行为冲突时，梯度信号按奇偶/表示结构相消——κ 可以
> 在训练前预告哪些数据会"静默拖累"，哪些目标函数能幸存。

## 2. 与现有工作的区别（必须写清）

| 工作 | 层级 | 我们的区别 |
|---|---|---|
| TRAJEVAL（AWS 2026-03） | 行为：search/read/edit 阶段分解 + 失败分类 | 我们做梯度层：信号幸存 |
| TrajAudit / AgentTether / AgentRx | 行为：轨迹失败诊断 + 运行时干预 | 同上 |
| RAGEN / RAGEN-2（Echo Trap / reasoning collapse） | 训练动力学：行为塌缩模式 | 我们做隐藏条件驱动的静默相消，且带闭式预测 |
| 多语言微调梯度冲突（2026-06） | 经验冲突测量（余弦相似度）+ 缓解 | 我们给出结构性判据与闭式（奇偶、方向、干涉） |

## 3. 决策（已定）

- 数据集：`SWE-smith-trajectories`（5k 条高质量轨迹，SWE-bench 实例，
  含 pass/fail、动作日志；规模适配 12GB 笔记本 GPU）
- 主条件变量：**gold-patch 解法类型**（按 gold patch 的编辑模式/涉及函数
  聚类定义隐藏条件）；备用可见条件（仓库领域 / 任务类型 / 语言）作对照
- 算力：本地 5070 Ti Laptop（12GB VRAM）
- 优先级：Paper 1 之后

## 4. Phase 0 — 条件显著性检验（纯 CPU，2-3 天，零训练）

**目标**：检验门 1——候选条件是否为行为的显著变量（510K 教训的前置门）。

**统计方案**：
1. 下载 SWE-smith-trajectories，解析条件标签（gold patch 聚类、仓库、语言、
   任务类型）与结果（pass/fail）+ 轨迹特征（步数、编辑次数、文件数）
2. 逐条件做：
   - 结果 × 条件：ANOVA / 卡方（组间方差 vs 组内噪声，仿 reveal 网格判决法）
   - 轨迹特征 × 条件：判别力（LDA 或简单分类器 AUC；特征分布 KL 散度）
3. 产出表格：条件 × 显著性

**止损线**：所有候选条件均弱驱动（p > 0.1 且判别 AUC ≈ 0.5）→ 关闭方向，
不进入 Phase 1。这是 510K 结论的同构：不是协议问题，是环境选择问题。

## 5. Phase 1 — 梯度测量（冻结小模型 + 12GB GPU，3-5 天，不训练）

**目标**：检验门 2——显著条件下的条件梯度是否真对抗（E_contrast > 0、
κ 显著 < 1），并测 κ↔结果相关性。

**方案**：
1. Qwen2.5-Coder-1.5B 冻结（bf16 ≈ 3-4GB），LoRA 不训练，只算梯度
2. 轨迹窗口截断：SWE-smith 平均 8-15k token，按 2-4k token 均匀采样子窗口
   （诊断不需要完整轨迹；或按阶段截取 edit 前窗口）
3. 按条件分组算期望梯度 → 直接复用现有测量机器：
   - E_shared / E_contrast / σ²（能量分解）
   - κ（幸存率）
   - N* 协议定样本量
4. 附加：测双通道干涉预测（熵/KL 系数 × κ 非单调——直接把 Paper 1 的
   Prop 3 预测搬到真实数据）

**产出**：条件对 × (κ, E_shared, E_contrast)；κ ↔ 条件成功率散点。

**门 2 判据**：κ 显著 < 1（E_contrast 占主导）且与结果相关 → 进 Phase 2；
κ ≈ 1（梯度全对齐，无冲突）或 κ 与结果无关 → 诚实收尾（可作边界论文）。

## 6. Phase 2 — 微调诊断演示 + 干预（仅两门全过才启动）

- LoRA 微调小模型（1.5B-3B，短上下文，12GB 可行）
- 诊断：训练停滞 run 的 κ/分解读数 vs 基线（reward 平坦度、路径积分）
- 干预：κ 指导的数据混合重加权（把高 E_contrast 的条件降权）——验证
  "诊断→修正"闭环，这是 oc_mem/O4 未竟的阳性实例候选
- 风险：LLM 梯度噪声大（510K σ² 教训）——用能量分解 + N* 防御，诚实报告
