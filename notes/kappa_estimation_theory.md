# κ 的有限样本估计与排序保证（理论推导）

> 补全 N* 定理：从"期望排序"到"以高概率排序正确"。
> 纯代数推导，无需计算。状态：推导稿。
> 最后更新：2026-08-03。

---

## 1. 估计器与期望（回顾）

条件 i 的两个关系（A/B）各有 N 个 episode 梯度，均值 ḡ_A, ḡ_B。两 rollout κ：

```
κ̂_N = ||(ḡ_A + ḡ_B)/2||² / ( (||ḡ_A||² + ||ḡ_B||²)/2 )
```

设 ḡ_A ~ N(μ_A, Σ_A/N)、ḡ_B ~ N(μ_B, Σ_B/N)（CLT，episode 独立）。记
μ = (μ_A+μ_B)/2，E_sh = ||μ||²，E_co = ||(μ_A−μ_B)/2||²，
E = E_sh + E_co = (||μ_A||²+||μ_B||²)/2。

**期望（N 偏置）**：E[κ̂_N] ≈ f(N) = E_sh/(E_sh + E_co + σ²/N)，其中
σ² = (tr Σ_A + tr Σ_B)/(2d) 的体量（各向同性近似）。

## 2. Delta-method 方差

κ̂_N = φ(ḡ_A, ḡ_B)，在 (μ_A, μ_B) 处：
```
∂φ/∂x = [ μ·E − E_sh·x ] / E²        (x = ḡ_A)
∂φ/∂y = [ μ·E − E_sh·y ] / E²        (y = ḡ_B)
```
故
```
Var(κ̂_N) ≈ (1/N) · [ (∇_A φ)ᵀ Σ_A (∇_A φ) + (∇_B φ)ᵀ Σ_B (∇_B φ) ]  ≡ V/N
```
V 完全由分量 (E_sh, E_co, μ, Σ_A, Σ_B) 决定——**可测、可算**。
各向同性近似 Σ_rel = σ²_rel I/d：
```
V ≈ (σ²_A ||∇_Aφ||² + σ²_B ||∇_Bφ||²) / N
```

## 3. 排序保证

对两个条件 i, j（真值 κ_true,i > κ_true,j）：
```
P( κ̂_N(i) > κ̂_N(j) ) ≈ Φ( (κ_true,i − κ_true,j) / √((V_i+V_j)/N) )
```
**达到 1−δ 置信所需样本**：
```
N(δ) = z_{1−δ}² · (V_i + V_j) / (κ_true,i − κ_true,j)²
```
其中 z_{1−δ} 是标准正态分位数（δ=0.05 → z≈1.96）。

## 4. 与 N* 定理的关系

- N* 定理：**期望**排序恒保持或单次穿越于 N*（线性结构）。
- 本结果：**概率**排序正确随 N 单调（Φ 是 N 的增函数），给出闭式 N(δ)。
- 合并协议：**取 N > max(N*, N(δ))** 即可同时保证期望与概率。

## 5. 与实测收敛曲线的一致性（验证公式可解释数据）

Toy REVEALED 实测：N=10 → ±0.019，N=50 → ±0.009，N=1000 → ±0.002。
若 Var(κ̂_N) = V/N：
- N=10→50：std 应按 √(50/10)=2.24 缩小 → 0.019/2.24 = 0.0085 ≈ 0.009 ✓
- N=50→1000：std 按 √(1000/50)=4.47 → 0.009/4.47 = 0.002 ✓
**1/√N 标度与实测完全吻合**——理论解释了我们观测到的收敛。

## 6. 开放项
