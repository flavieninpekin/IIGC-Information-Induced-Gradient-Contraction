# 连续揭露实验：κ 的方差分解、谷的机制与"关系深度"代理

> 目标：把"信息揭露比例 p → κ(p)"的曲线建模成可测量的量，用全方差律把
> κ 的下降分解为"deal 对比"与"混淆噪声 σ²(p)"两部分，从而：
> 1. 解释谷（dip）为何出现、预测其位置（机制指纹）
> 2. 给出 σ²(p) 的操作化测量协议（不靠猜测）
> 3. 提出"关系深度 = 1 − κ(1)"作为环境/任务结构的代理量
> 最后更新：2026-07-31。

---

## 1. 设定

- 关系变量 z（队友身份）由每局发牌决定（510K dynamic），或由 set_partner
  强制（Toy）。
- 训练时观测中的关系信息以概率 p 保留、以概率 (1−p) 被掩码清零。
  **掩码不可观测**：清零的位与"本来就不是队友"不可区分。
- 训练完成后，在**全信息（obvious/full reveal）评估**下测量梯度 g 与 κ。

## 2. 基础关系：κ = 信号比

对梯度估计量 g（一个 episode 的累计梯度），两个 rollout 的 κ 估计的是

```
κ(p) = ||E[g]||² / ( ||E[g]||² + Var(g) )        (1)
```

证明：κ = ||(g_A+g_B)/2||² / avg(||g_A||²,||g_B||²)。
令 g = μ + η，η 零均值噪声，则 ||(g_A+g_B)/2||² ≈ ||μ||²，
avg(||g||²) ≈ ||μ||² + Var(g)。代入即得。

**推论**：κ 的极小值 = Var(g)/||μ||² 的极大值。极值位置由梯度方差的
结构决定——这就是理论可预测的东西。

## 3. 全方差分解：σ²(p) 的操作化定义

把梯度方差按"关系（deal/partner）"分组：

```
Var(g) = Var_rel( E[g|rel] )  +  E_rel( Var(g|rel) )
         └──────┬──────┘        └───────┬───────┘
         Var_between（deal 对比）     Var_within（混淆噪声）
```

- **Var_between**：各关系条件均值 E[g|rel] 之间的方差 → 公式里的 (2a−1)²c²，
  是"策略正确使用关系信息"产生的对比。
- **Var_within**：给定关系时梯度自身的方差 → 这就是 **σ²(p)**（策略的
  混淆噪声 + action 随机性）。

### 测量协议

1. 收集大量 episode 的梯度 g，每个 episode 记录其关系 rel（固定发牌/
   set_partner 强制，或事后从游戏状态读出）。
2. 分组：对每个 rel 计算条件均值 μ_rel = E[g|rel]。
   - Var_between = (1/R) Σ_rel ||μ_rel − μ||²，μ = (1/R)Σ_rel μ_rel
   - Var_within  = (1/R) Σ_rel E[ ||g − μ_rel||² | rel ]
3. **一致性检验（模型自洽）**：验证
   ```
   Var_total = Var_between + Var_within        (2)
   ```
   用全部样本算 Var_total = E[||g−μ||²]。等式成立说明分解干净。
   （Toy 原型实测：精确到 ~1e-6。）
4. **分离 action 随机性**：用 deterministic 采样重测同一协议。固定关系 +
   deterministic → 组内方差应趋近 0；剩下的组内方差才是纯 σ²(p)
   （策略内部的混淆，不来自采样）。

## 4. 机制模型、谷的来源与极值预测

### 4.1 梯度模型

策略在关系 rel 下的梯度可写为三个正交分量：

```
g(rel) = m + w(p)·s_rel + ε(p)
         ↑共享     ↑条件对比     ↑混淆噪声
```

- **m**：共享边际梯度（deal 无关，如"好好打牌"）→ 永远对齐 → 抬 κ
- **s_A = −s_B = c**：条件对比（deal 相反）→ w 越大对比越强 → 压 κ（单调）
- **ε**：混淆噪声，Var ε = σ²(p)

κ̂(p) = m² / (m² + w(p)²c² + σ²(p))           (3)

### 4.2 谷的来源："committed but wrong"（已证伪，2026-08-01）

> ⚠️ **状态：已证伪。** 早期推导假设"错误条件化 → 指向错误最优的反向梯度"
> （σ² ∝ w(1−a)，E_contrast+σ² = c² 与 a 无关 → κ 平坦）。Toy 上注入
> 估计错误的验证（`toy/verify_accuracy_invariance.py`）**推翻**了它：
> E_contrast+σ² 从 486 单调崩到 2.0，κ 从 0.37 降到 0.10，均不平坦。
> 原因：**±1 奖励的 REINFORCE 下，错误动作得 −1 → 梯度反而更用力推向
> 正确动作（修正），准确率 a 调制的是梯度幅值，不是对比/噪声的互补分配。**
> 模型的核心假设需要非对称奖励或能产生真反向梯度的梯度结构才可能成立。
> 以下保留为历史推导，不再作为可发表的机制。

σ²(p) 来自策略**自信地犯错**——它学会了**信任**队友信号（权重 w(p)），
但学到的映射有错误率 (1−a(p))：

```
σ²(p) ∝ w(p) · (1 − a(p))      ← "下注了但错" 的强度（历史推导，已证伪）
```

- **低 p**：信号太不可靠 → 策略学会忽略（w≈0）→ 一致 → κ 高
- **高 p**：信号可靠 → 学会完全正确地条件化（w≈1, a≈1）→ 一致 → κ 高
- **中间 p**：信号"够好"让策略下注（w 大），但映射仍错（1−a 大）→ 最矛盾 → κ 塌

若 a(p)≈p（策略学会真实揭露率）且 w(p)=p^k（信任超线性），则
σ² ∝ p^k(1−p)，峰在 **p* = k/(k+1)**。观测到 75% 谷 → k≈3，即
"策略一旦觉得信号够可靠就强烈下注"。

> **证伪讨论**：这个机制预测"谷"和"平坦 κ 由互补相消解释"——两者都错。
> 510K 实测 κ(p) 平坦（ANOVA p=0.76），且 Toy 注入验证显示互补相消不成立。
> 平坦 κ 的更可能解释是：混合协议下单集梯度噪声主导测量（见 §7.2），
> 而非机制性相消。若要在非对称奖励设定下重试"committed but wrong"，
> 需要一种梯度结构使错误条件化产生真反向更新。

### 4.3 极值位置是机制的指纹

| 机制 | a(p) / σ²(p) 形式 | 预测极值 p* |
|---|---|---|
| 纯掩码方差 | 策略信任 ∝ p，σ² ∝ p(1−p) | p* = 0.5（Bernoulli 方差最大） |
| 信任超线性 | a(p) 随 p 快速饱和（如 ∝ p^k） | p* = k/(k+1)（右移） |
| 无塌陷 | σ² 单调/无峰 | κ(p) 单调，无内部极值 |

## 5. 判别式：谷 vs 单调（m/c regime）

**谷是否出现，由 m 与 c 的比例决定**：

```
κ(p) 单调下降（Toy）  ⟺  c 主导，μ² 塌缩
                       └─ p→1 时条件梯度精确反对称 → μ=(μ_A+μ_B)/2≈0
κ(p) 有谷（510K?）    ⟺  m 主导，μ² 存活，σ² 峰透出
```

端点 κ(1) ≈ m²/(m²+c²) 直接反映 m/c 比例：
- Toy（2 动作 × 二值关系）：c 主导 → κ(1)≈0.105 → 单调
- 510K（300 动作 × 复杂关系）：m 主导 → κ(1)≈0.616 → 谷可出现

**判别式（可测量）**：先测 κ(1)。若 κ(1) 高（m 主导），细网格值得做
（预期有谷）；若 κ(1) 低（c 主导），预期单调，不必找极值。

## 6. "关系深度"代理：1 − κ(1)

```
关系深度 = 1 − κ(1) ≈ c²/(m²+c²)
         = 梯度能量中由（隐藏）关系驱动的比例
```

它代理的不是笼统的"规则复杂程度"，而是**"关系中心性 / 关系深度"**——
任务里有多大比例的决策被关系变量主导。

| 环境 | 规则 | 关系在策略中的占比 | κ(1) 预期 | reveal 曲线 |
|---|---|---|---|---|
| Toy | 极简 | 关系=全部（c 主导） | ~0.1 | 单调塌缩 |
| Overcooked 角色任务 | 中 | 关系很中心 | 低 | 大概率单调 |
| 510K | 复杂 | 关系只占一小部分（m 主导） | ~0.62 | **有谷** |

**用途**：
1. 环境排序：用 κ(1) 给环境排"关系深度"——补上上一篇文章
   gap_analysis 缺的"Δκ vs 环境复杂度"表格
2. 预测 reveal 干预的价值：关系深度低 → 揭露关系才有意义；关系深度高
   → 一次性揭露，别给一半
3. 边界条件刻画：从"哪些环境放大 IIGC"变为"哪些环境 m/c 大 → 谷出现"

**Caveat（重要）**：m/c 是**策略依赖**的，不是环境不变量——随训练/适应
变化（E2 的"已适应策略"教训）。作为代理需用**规范化策略**（充分训练、
固定协议）测量，或把"策略依赖"本身作为研究对象（未适应 vs 已适应的
关系深度变化）。

## 7. 模型验证闭环（含已验证的结果）

```
理论: κ̂(p) = m²/(m² + w(p)²c² + σ²(p))        [a(p),w(p) 由损坏统计拟合]
测量: 全方差律 → 直接量出 σ²(p)、c、m、Var_between、Var_within
检验: ① 守恒检验 (2) 成立  ② 拟合 κ̂(p) vs 实测 κ(p) 吻合
     ③ 极值点 p* 与实测 dip 一致  ④ Var_within(p) 峰与 dip 位置一致
```

### 7.1 已验证：能量-方差分解（Toy 强制分配，2026-08-01）

`experiments/common_basis/toy/verify_energy_decomp.py`，结果存于
`data/kappa/energy_decomp/results.json`。三个恒等式全部精确成立：

| 恒等式 | HIDDEN | REVEALED |
|---|---|---|
| **Pythagorean**：(‖g_A‖²+‖g_B‖²)/2 = E_shared + E_contrast | err 5.7e-14 | 1.5e-8 |
| **全方差律**：Var_total = Var_between + σ² | err 1.8e-5 | 3.6e-7 |
| **κ_mean = E_shared/(E_shared+E_contrast)** | 0.000 = 0.000 | 0.360 = 0.360 |

**结论**：κ 不是黑箱——它精确等于"共享能量占比"；梯度能量（Pythagorean）
与梯度方差（全方差律）都正交分解为可测分量（shared / contrast / σ²）。
HIDDEN 时 E_shared=0（完全抵消 → κ=0），REVEALED 时 E_shared>0（有保留）。
这是上一篇 Pythagorean 分解的操作化 + 验证，可独立发表。

### 7.2 已证伪：连续揭露极值预测（510K，2026-08-01）

`experiments/common_basis/reveal/`，126 个模型（21 档 × 6 种子），
`data/kappa/510k_reveal/results.json`。

- κ(p) 统计平坦 ~0.50：ANOVA F=0.756, p=0.759；逐点 Bonferroni 全 p=1.000；
  75% vs 邻居 p=0.608；相邻对 0/20 显著。
- **"75% 谷"是 n=2 的采样假象**。极值预测 / almost-right penalty 框架不成立。
- 附加发现：κ≈0.50 = 两个 rollout 梯度正交值 → 混合协议下 κ 被单集噪声主导
  （~1.6e6 vs 队间对比 ~2.5e4），**510K 混合协议对 κ 不够灵敏**。

## 8. 与 Toy / 510K 的衔接（当前实验状态）

**Toy 原型已完成**（`experiments/common_basis/reveal/`、`toy/`）：
- 守恒检验成立（~1e-6）；能量-方差分解恒等式全部验证（见 7.1）
- **σ²(p) 在 p=0.3 出现预测的中间峰**（var_within: 0.69→2.93→0.68）——
  "confused at intermediate reveal" 机制在 Toy 上直接测到
- 但 κ 无谷（强制协议单调下降；混合协议持平 ~0.9）——因为 Toy 是
  c 主导（μ² 塌缩）或混合平均稀释，符合第 5 节判别式

**510K 全网格已完成**（21 档 × 6 种子，126 模型）：
- **κ(p) 统计平坦**（ANOVA p=0.759），"75% 谷"为 n=2 假象（见 7.2）
- 混合协议下 κ 被单集噪声主导 → 该协议对 κ 不够灵敏
- 若要测 510K 的 σ² 分解，需强制分配协议（固定红A持有者的受控发牌）
