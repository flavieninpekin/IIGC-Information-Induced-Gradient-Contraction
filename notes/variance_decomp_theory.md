# 紧凑测量的排序保持：形式化结果

> 问题：用 N 个 episode 的紧凑测量代替大样本测量（N→∞）时，κ 的估计值
> 有偏（σ²/N 项），且偏置因条件而异。**排序/趋势是否保持？**
> 结论：可以证明——**一般不保证，但失效是完全可刻画的一次穿越**。
> 最后更新：2026-08-01。

---

## 1. 设定

条件 i 的有限样本 κ 期望（忽略估计方差）：

```
f_i(N) = a_i / (a_i + b_i + c_i / N)        (1)
```

其中 a_i = E_shared（共享能量），b_i = E_contrast（对比能量），
c_i = σ²_i（噪声方差）。N→∞ 时 f_i(N) → κ_true,i = a_i/(a_i+b_i)。

f_i 是 N 的增函数（更多样本 → 噪声惩罚小 → κ 高），对每个条件单调。

## 2. 定理（单次穿越）

对两个条件 i, j，定义 N>0：

```
f_i(N) − f_j(N)
  =  N · [ (a_i b_j − a_j b_i)·N + (a_i c_j − a_j c_i) ]
     / [ ((a_i+b_i)N + c_i)·((a_j+b_j)N + c_j) ]        (2)
```

分母恒正，N>0，故

```
sign( f_i(N) − f_j(N) ) = sign( (a_i b_j − a_j b_i)·N + (a_i c_j − a_j c_i) )   (3)
```

右边是 N 的**线性函数**，因此：

- 若 `a_i b_j − a_j b_i` 与 `a_i c_j − a_j c_i` **同号** → 排序对一切 N 保持。
- 若**异号** → 两条曲线**恰好穿越一次**，穿越点为

```
N* = (a_j c_i − a_i c_j) / (a_i b_j − a_j b_i)            (4)
```

且 N > N* 时回到大样本（真值）排序。

## 3. 推论（排序保持的充要条件）

注意到：
- `a_i b_j − a_j b_i > 0 ⟺ a_i/b_i > a_j/b_j ⟺ κ_true,i > κ_true,j`（正比于信号比）
- `a_i c_j − a_j c_i > 0 ⟺ a_i/c_i > a_j/c_j`（正比于信噪比 a/σ²）

所以排序对**所有 N** 保持 ⟺ 两个条件在 **κ_true** 和 **a/σ²（共享能量/噪声）**
两个排序上**一致**：

```
sign(κ_true,i − κ_true,j) = sign(a_i/σ²_i − a_j/σ²_j)  对所有 i,j   (5)
```

## 4. 机制解释

紧凑测量系统性**惩罚噪声大的条件**（大 σ² 的 f_i(N) 在有限 N 被压低更多）。
若一个真值 κ 高但信噪比低的条件，在 N 小时可能被排到"真值 κ 低但噪声低"
的条件之下——**趋势翻转**。翻转恰好一次，在 N* 处，之后恢复。

## 5. 实用协议（保证排序可信）

1. 测每个条件的 (a, b, c)。
2. 对要比较的每一对，按 (4) 计算 N*。
3. **取 N > max N*** 即可保证观测到的排序 = 真值排序（以高概率）。

若条件在 (5) 上排序一致，则任意 N 都保序——紧凑测量直接可用。

## 6. 反例（构造）

条件 i：a=1, b=0（κ_true=1），c=100（噪声极大）→ 信噪比 0.01。
条件 j：a=1, b=1（κ_true=0.5），c=1（噪声小）→ 信噪比 1。

κ_true: i > j；a/σ²: i < j → 异号 → 必穿越。
(4): N* = (a_j c_i − a_i c_j)/(a_i b_j − a_j b_i) = (1·100 − 1·1)/(1·1 − 1·0) = 99。

- N=10：f_i=1/(1+10)=0.091 < f_j=1/(2+0.1)=0.476 → **j 反超 i（翻转）**
- N=1000：f_i=0.909 > f_j=0.5 → 恢复真值排序
