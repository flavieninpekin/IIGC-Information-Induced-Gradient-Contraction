## 1. 一句话主张（候选）

> 当训练数据由一个**隐藏变量**分层、且该变量的不同取值通过一个对称群 G 作用于
> 学习目标时，聚合更新只能保留目标中 G-不变的分量；非不变分量按表示论规则
> 精确（对称设计）或定量（非对称混合）湮灭。幸存率可闭式计算，
> 且给出"哪些损失函数/架构能绕开湮灭"的先验判据。

大白话：看不见的条件在目标里留下的"方向性指纹"，会被平均操作按对称性的
频谱精确抹掉——抹掉多少、留多少、谁能活，全部可以先算出来。

## 2. 形式设定

- 参数 θ ∈ Θ，条件条件化梯度 g_z(θ) = ∇_θ L_z(θ)，z ∈ 𝒵 为隐藏变量。
- 存在群 G 作用于目标空间（对 RL：Q→Q∘g 的值变换；对监督：标签变换 y→g·y），
  使 g_{g·z} = ρ(g) g_z，其中 ρ 是梯度场诱导的表示。
- 训练更新方向 = 混合期望 ĝ = E_{z∼p}[g_z]。
- 定义幸存率（现有 κ 的推广）：κ = ‖ĝ‖²_{J} / E_z‖g_z‖²_{J}，
  J 为 Fisher 度量（均匀策略退化为欧氏，连接 C.4.3）。

## 3. 核心引理（待证明/证伪——本文档的存在理由）

**引理 S（谱幸存，猜）**：将 {g_z} 张成的空间按 G 分解为不可约表示直和
⊕_λ V_λ。则
1. 对称设计 p（p 不变于 G 的作用）：ĝ 只含平凡表示 V_triv 分量；
   κ = ‖proj_triv g‖²/E‖g‖²，与各非平凡分量的能量无关。
2. 非对称混合：非平凡分量按 p 与 G-轨道的交叠部分幸存，幸存率有显式的
   群重排不等式/等式（Z₂ 时已知：κ = (Σ轨道内系数和)²/…，见 §4）。
3. 动力学版本（更强，可能不真）：SGD 从任意初始化出发收敛到只含不变
   分量的解类——即"湮灭不只是梯度一步的性质，还是吸引子"。

**检验用最小群**：G=Z₂（已有完整答案，命题 A/B/C 全部应为推论）；
G=S₃（三条件轮换，如三人合作任务）；G=(Z₂)²（两维独立隐藏位）。
若 S₃ 上出现 Z₂ 直觉无法预言的现象（如两个非平凡表示的干涉），
框架就有超出"奇偶推广"的新内容——这正是要找的。

## 8. S₃ 判决详情（2026-08-26，`verify_s3_survival.py` → `s3_survival.json`）

设定：3 条件/3 动作匹配带臂机，Q_i(a_j)=2Rδ_ij，softmax π，规范期望梯度，
κ(p) := ‖Σ_i p_i g_i‖² / E_i‖g_i‖²（p 为隐藏条件的训练分布）。

**结果一（对称设计湮灭的群推广）**：p 均匀时 reinforce/expq κ≈1e-32——
swap 相消定理对非交换群精确成立。

**结果二（方向结构，Z₂ 不可能）**：固定混合分布到均匀点的 L1 距离、扫方向：
κ 最大相差 2.5×（dist=0.45 时 [0.075, 0.192]）。**幸存率依赖条件分布的方向，
不只幅度**——Z₂ 里不对称只有一种方式，此现象结构性不可见。
expq 有完整闭式：ĝ_p[b] ∝ π_b(p_b − ⟨p,π⟩)，机器精度验证。

**结果三（双通道干涉，本轮最大意外）**：softq 的 κ(α) 在非对称混合下**非单调**
（p=(0.7,0.2,0.1)：0.396@α=0.05 → 0.032@α=2 → 0.415@α=5）。机制：熵通道
α(ℓ−ℓ̄) 与混合通道 −2R(p−ṗ) 同处二维切空间、作为向量相加，可相消性干涉；
Z₂ 切空间一维、所有分量共线，干涉结构性不可能。双通道闭式：
```
κ_softq(p,π,α) = Σ_b π_b²[α(ℓ_b−ℓ̄) − 2R(p_b−ṗ)]²
                 / mean_i Σ_b π_b²[α(ℓ_b−ℓ̄) − 2R(δ_ib−π_i)]²   （机器精度验证）
```
可检验预测：**熵正则化调错会把非对称隐藏条件下的训练信号静默调没**
（存在破坏性 α*），这对 RLHF/多任务的超参实践有直接警示意义。

**论文叙事升级**："从 Z₂ 到一般 G"不再是抽象推广——切空间维数 ≥2 是
新现象（方向依赖、通道干涉）的真实来源，这给了表示论视角独立的必要性。

## 8b. 结构轴判决（2026-08-26，`verify_structure_axis.py` → `structure_axis.json`）

Z₂ 带臂机、非对称目标 Q_A=(r,−r)、Q_B=(−s,+s)，扫 s/r∈[0,1]，均匀混合。

| s/r | expq（PG 场）κ | TD 场 κ |
|---|---|---|
| 1.00（纯镜像） | 0.0000 | 0.0006 ± 0.0004 |
| 0.50 | 0.1000 | 0.0009 ± 0.0006 |
| 0.00（B 无冲突） | **0.5000** | 0.0007 ± 0.0004 |

**判决：结构轴按场类型分裂，不是单根轴。**

1. **PG/奇场**：κ = (r−s)²/(2(r²+s²)) 闭式，机器精度验证（1.4e-17）；
   结构不对称**救活**奇场——幸存率由"目标落在平凡表示上的能量占比"决定。
2. **TD/值场**：收敛点处对**任意** s/r 精确塌缩（κ≈0.001）。手推原因：
   收敛值函数 = 关系均值 Q̄，此时条件残差 e_B = −e_A 对一切 s/r 成立
   （均匀混合下）→ g_B = −g_A → 湮灭与结构无关。
3. **对 E3 遗留之谜的修正**：E3 在 ρ=0 测到 κ_TD=0.5，本实验收敛充分后
   测到 0.001——E3 高值来自欠收敛/采样测量协议，非结构效应。暂态扫描
   （step 50-3000）全程小，暂态幸存故事在此设定下不显著。对账问题保留。
4. **真实环境 value 场高 κ 的新解释**：不是"TD 按构造对齐"，而是
   "真实模型永不处收敛固定点 + 观测级非镜像"——训练动态视角，可写成
   与 E3/O4 一致的统一叙述。

**论文新情节**："结构轴"实际是**场依赖的**——同一结构变化对 PG 与 TD
有相反意义。这进一步支撑群论框架：幸存由"目标表示分解（决定奇场）"
与"动态固定点（决定偶场）"两个机制共同决定。

### 7.3 判决

**立题成立，但需三处显式定位**：
1. **风险空间 vs 梯度空间**（对 Symmetrization/Unhinged 线）：我们是结构化异质
   性下的梯度幸存，含闭式与 Z₂/S₃ 新现象；
2. **机制 vs 缓解**（对 MTL/FL/RLHF 线）：先有"何时必然湮灭"的判据，才有
   缓解的空间；
3. **RLHF 章节是加分项且时机好**（2026 年该方向活跃），但要写成"我们的代数
   补全他们的经验观察"，不抢公平性叙事。
