# 论文脊柱（抗散射的总纲）

> 目的：把散落的实验收敛成一条连贯的主线。所有东西按
> **核心贡献 / 动机 / 负面结果 / 弃用方向** 归位。
> 之后的新实验都应挂在脊柱上，否则不做。

---

## 一句话贡献

> **梯度保留率 κ 可被分解成三个可测分量（共享/对比/噪声），
> 且分解后的 κ 可跨样本预测、可紧凑测量、排序有保证、比 κ 本身更有信息量。**
> —— 一个"可信任的诊断"：用小样本、便宜测量替代大样本、昂贵测量，
> 并知道边界在哪。

## 脊柱（论文结构）

### 1. 问题：Stable-or-Stuck
训练曲线平坦，无法区分"已收敛"和"信息卡死"。κ（梯度保留率）是候选诊断
——但用之前没人证明它能信任。

### 2. 方法：κ 的分解
```
κ = E_shared / (E_shared + E_contrast + σ²)
```
E_shared=共享能量、E_contrast=关系对比、σ²=噪声。强制分配（set_partner）
下三分量可直接测量，无需黑箱。

### 3. 四个已验证性质（实证支撑）
| # | 性质 | 证据 | 状态 |
|---|------|------|------|
| P1 | **精确分解**（Pythagorean + 全方差律） | err 1e-14 / 1e-5 | ✓ |
| P2 | **跨样本可预测**（去循环） | 误差 0.04 (REV) / 0.00 (HID) | ✓ |
| P3 | **可紧凑测量** | N=50 → ±0.009；排序定理 N* | ✓ |
| P4 | **比 κ 信息量大**（尺度失明） | κ 不变 vs 分量 λ² 缩放 | ✓ |

排序保持定理（`notes/variance_decomp_theory.md`）：f_i(N)−f_j(N) 是 N 的
线性函数 → 排序恒保持或单次翻转，翻转点 N*=…，实用协议"N>max N*"。

### 4. 动机/应用：IIGC
隐藏关系把 mode-seeking 梯度场确定性抵消（Toy：κ=0.000±0.000）。这就是
诊断要服务的现象——当 κ 低时，先怀疑信息结构而非算法。

### 5. 负面结果作为方法验证（诚实收尾）
- 510K 连续揭露"谷"是 n=2 假象（126 模型 ANOVA p=0.76）
- 混合协议测 κ 被单集噪声主导（协议不灵敏的教训）
- 我们的协议（能量门/强制分配/守恒检验）正是能暴露这些假象的工具

**破局动作（最该做的一件事，已修正）**：
原计划在 510K 做 stuck 检测，但三次尝试（混合 κ / 强制分配分解 / 敏感性探针）
都失败——**510K 的关系（队友分配）是策略的弱行为驱动**（116 维观测里的 4 位、
对行为影响甚微），所以关系条件诊断在那里天然区分不了。应用验证移到
**Overcooked（chef/waiter 角色，关系就是任务本身）**——见
`notes/app_validation.md`。若 Overcooked 也弱，则接受"诊断只在关系相关的
环境中可用"的诚实边界，论文降级为方法学（性质 + 理论 + 边界）。

> ⚠️ 已知：κ-as-forecaster 在历史数据失败；510K 三次应用尝试因关系弱驱动失败。
> 区别：Stable-or-Stuck 是**分类当前状态**，非预测未来 reward；但前提是
> 该环境的关系确实是行为的显著变量。
