## 1. 一般结构定理：平凡投影幸存

**设定。** 条件 i ∈ G（|G| = n 有限群，本文 Z₂、S₃）；目标 Q_{σ·i} = ρ(σ)Q_i
（ρ 为表示）；策略 π 看不到条件；损失诱导条件条件化期望梯度 g_i = ∇L_i。
定义混合算子 E_p[g] = Σ_i p_i g_i，κ(p) = ‖E_p[g]‖² / E_{Unif}‖g_i‖²。

**定理 1（平凡投影幸存）。** 设条件梯度满足分解
    g_i = h + g'_i，  h 与条件无关， Σ_{i∈G} g'_i = 0。
则均匀混合下
    ĝ = h，  κ = ‖h‖² / (1/n)Σ_i‖g_i‖²。

*证明。* ĝ = (1/n)Σ_i g_i = h + (1/n)Σ_i g'_i = h。κ 代入定义即得。∎

*表示论读法。* 置换表示 ρ_perm 分解为平凡 ⊕ 标准表示；Σ_i g'_i = 0 恰为
"g' 无平凡分量"；均匀平均算子 = 平凡投影（Schur 正交性）。**混合即投影，
投影即湮灭非不变分量。**

**推论 1（奇场精确相消）。** 任何权重逐元素且参数无关的场（reinforce、
expq、awr 无 baseline、softmax(Q/τ)），其梯度满足 h = 0、g'_i = g_i、
Σ_i g'_i = 0，故均匀混合下 κ = 0 精确。
*验证：* Z₂ 与 S₃，κ ≈ 1e-32（3 seeds）。∎

**推论 2（softq 幸存机制 = 不变分量）。** softq 的熵项 α⟨π,logπ⟩ 与条件
无关，故 h = 熵梯度（非零），恰为幸存来源——奇偶图景下"偶分量"的群论身份
就是平凡表示分量。∎

## 2. expq 闭式与方向依赖（S₃）

**命题 2。** expq（L_i = −⟨π,Q_i⟩，Q_i(j) = 2R·δ_ij）：
    g_i[b] = −2R π_b (δ_ib − π_i)，
    ĝ_p[b] = −2R π_b (p_b − ⟨p,π⟩)，
    κ(p,π) = [Σ_b π_b² (p_b − ⟨p,π⟩)²] / [(1/3) Σ_i Σ_b π_b² (δ_ib − π_i)²]。

*证明。* ⟨π,Q_i⟩ = 2Rπ_i；∂_b⟨π,Q_i⟩ = Σ_a π_a(δ_ab − π_b)Q_i(a) =
π_b(Q_i(b) − ⟨π,Q_i⟩) = 2Rπ_b(δ_ib − π_i)。expq 损失取负号即 g_i。混合：
Σ_i p_i(δ_ib − π_i) = p_b − ⟨p,π⟩。∎

**方向依赖（命题 2b）。** 对固定 L1 距离 d = ‖p − 1/3‖₁，κ 不是常数：
    sup κ − inf κ ≥ 0.12（d = 0.45，24 方向，实测 [0.075, 0.192]）。
*结构原因：* κ 只经 u(p) = p − ⟨p,π⟩·1 依赖 p，而 u 是混合单纯形到
π-正交补的投影；切空间二维 ⟹ 固定 L1 距离的水平集是一维曲线，κ 沿之
变化。Z₂ 情形切空间一维，水平集为单点，此现象结构性不可能。∎
（"仅方向决定、与幅度无关"的解析证明：对任何满足 ⟨p−1/3,π⟩ 相同的
方向族，κ 由 u(p) 的 π² 范数与方向决定——留作引理 2c，数值已验。）

## 3. 双通道干涉（softq）— 非单调性的完整刻画

**命题 3。** softq（L_i = Σ_a π_a(α log π_a − Q_i(a))）：
    g_i[b] = π_b [ αA_b − 2R C_ib ]，  A_b = ℓ_b − ℓ̄，C_ib = δ_ib − π_i
    ĝ_p[b] = π_b [ αA_b − 2R B_b ]，   B_b = p_b − ⟨p,π⟩
    κ(α) = num(α) / den(α)，
    num(α) = α²‖A‖²_{π²} − 4Rα⟨A,B⟩_{π²} + 4R²‖B‖²_{π²}，
    den(α) = α²‖A‖²_{π²} + (4R²/3) ‖C‖²_{π²}。

*证明。* 直接求导：∂L_i/∂z_b = αΣ_a π_a(δ_ab−π_b)(logπ_a+1) − π_b(Q_i(b)−⟨π,Q_i⟩)
= απ_b(ℓ_b−ℓ̄) − 2Rπ_b(δ_ib−π_i)。混合同理。∎

**命题 3b（非单调判据）。** 若 ⟨A,B⟩_{π²} > 0，则 κ(α) 有内点极小：
    κ'(0) < 0，  κ(α*) < κ(0)（α* = 2R⟨A,B⟩_{π²}/‖A‖²_{π²}），  κ(∞) = 1。

*证明。* (i) den 无 α 线性项：Σ_i C_ib = 1 − 1 = 0 消掉交叉项 ⟹ den 关于
|α| 凸增。(ii) num'(0) = −4R⟨A,B⟩ ⟹ κ'(0) = num'(0)/den(0) < 0。(iii)
num 的极小点在 α*（num'(α*) = 0）；num(α*) < num(0) 且 den(α*) > den(0)
⟹ κ(α*) < κ(0)。(iv) num/den 的 α² 系数皆为 ‖A‖²_{π²} ⟹ κ(∞) = 1。
故 κ 先降后升，非单调。∎

*可检验预测。* 熵方向与混合方向正对齐时（⟨A,B⟩ > 0），调大熵系数会**先**
抹掉幸存信号再恢复——"熵正则化调错静默摧毁训练信号"。实测（p=(0.7,0.2,0.1)）：
κ(α) = 0.396 → 0.032 → 0.415，闭式 vs autograd 最大误差 3.3e-16。∎

## 4. 结构轴：场类型分裂（Z₂ 非对称）

**设定。** Q_A = (r,−r)，Q_B = (−s,+s)，均匀混合，u = (1,−1)。

**命题 4a（奇场复活）。** expq/reinforce：
    κ = (r−s)² / (2(r²+s²))。
*证明。* 由 §2 公式：g_A = −2rpq·u，g_B = +2spq·u；E_shared =
‖pq(s−r)u‖² = 2p²q²(s−r)²；E_total = (4r²p²q²·2 + 4s²p²q²·2)/2 =
4p²q²(r²+s²)。κ = (r−s)²/(2(r²+s²))。∎
s=r ⟹ κ=0（镜像，推论 1）；s=0 ⟹ κ=1/2。验证到 1.4e-17。

**命题 4b（TD 收敛点塌缩）。** 设 Q 网收敛到 TD 定点。均匀混合下一步带臂机
的定点为 Q̄ = E[Q] = ((r−s)/2, (s−r)/2)。条件残差
    e_A = Q̄ − Q_A = −((r+s)/2)·u，  e_B = Q̄ − Q_B = +((r+s)/2)·u = −e_A。
TD 梯度 g_i = J e_i（J 为 Q 网参数 Jacobian），故 g_B = −g_A，κ = 0 对一切 s/r。
*实测：* s/r ∈ {1.0 … 0.0} 全部 0.001 ± 0.001（5 seeds）。
*注意：* 论断是渐近的（定点处）；训练中 κ 有暂态（本设定下实测小，E3 的高值
归因欠收敛 + 采样协议，见 sketch note §8b.3）。∎

## 5. 动力学：吸引子结构（2026-08-26 判决——直觉被数值纠正）

> 最初猜想 C1"偶场收敛到 G-不变点"在 softq 上**证伪**。softmax 参数化的
> 软熵正则项的梯度流是 **mode-seeking 的**（把 π 推向峰值），不是推向均匀。
> 数值差分（FD vs 理论，机器精度一致）+ 梯度流模拟共同确认。正确结论：

**命题 5（吸引子结构，toy 版）**。对称镜像带臂机（Z₂ 或 S₃，均匀混合）：
(a) **奇场（expq/reinforce）**：梯度恒零 ⟹ 策略冻结在初始化（初值即
吸收态）。"不动"是精确的，不是收敛。
(b) **softq**：仅剩熵通道 `2α·∇_z H`；softmax 参数化下该流是 mode-seeking
（dz/dt ∝ π_b(ℓ_b−ℓ̄) 沿高概率动作方向），收敛到**峰化**（对称破缺吸引子），
而非均匀。KL 直觉（π-空间复制动力学收敛均匀）**不能**搬到 z-空间。
(c) **TD**：Q 收敛到关系均值 Q̄ = 0（对称），策略（argmax/softmax 于 Q̄）
退化为均匀——**收敛到 G-不变点的是 TD**，与直觉相反的是 softq。

*验证：* 梯度流模拟（z=[3,−3]，lr=0.05，3000 步）：π₀ 0.9975→0.9998（峰化，
softq）；FD 梯度与解析式逐位一致。∎

**对论文的含义（重要）**：静态几何（命题 1-4）与动力学（命题 5）是两回事。
"偶分量幸存"是**单步梯度**性质；吸引子结构随场而异——softq 的幸存通道把
策略推向确定性（用光幸存信号），TD 的定点则让策略退回均匀。这解释了
E1"critic 反而 S>D"的一角，也把"幸存—失明"叙事推进为"幸存—自噬"：
**softq 的熵通道在动力学上吃掉自己幸存下来的锐度。**

## 5b. 一般群猜想（开放）

- **C2（一般群）**：定理 1 对任意有限群 G 成立（平均算子 = 平凡投影，
  Schur）；二维不可约表示催生方向依赖与干涉。Z₂/S₃ 已验证；非置换表示
  （如 (Z₂)² 双符号）待验。
- **C3（真实环境）**：命题 5 的吸引子结构在非镜像/非平稳环境中是否保持
  ——Overcooked value 场 κ≈0.98 与 Toy 的塌缩之间的桥（动态假说，待实验）。

## 6. 与 Fisher 度量的关系

κ 以欧氏范数定义；在指数族参数化（z ↔ π）下，切空间的 Fisher 度量与
simplex 的 standard 几何一致，命题在两种参数化下同构。C.4.3 中"Fisher
加权"的担忧在此设定下退化——这是 toy 的特殊性，写进论文时注明。
