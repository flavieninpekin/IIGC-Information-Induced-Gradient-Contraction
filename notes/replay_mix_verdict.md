# E3 判决：replay 混合消融（Toy 镜像带臂机）— 假设被拒绝，闭式吻合

> 实验：`experiments/common_basis/replay_mix/run_toy_replay_mix.py`
> 数据：`data/kappa/replay_mix/toy_mix_results.json`
> 判决：**"TD 调和机制"（κ_TD 随混合度上升）在 Toy 上被拒绝**——实测单调下降，
> 与闭式 (1−2ρ)²/(2(ρ²+(1−ρ)²)) 吻合。2026-08-22。

---

## 1. 假设（来自 kappa_reversal_discussion.md §6 / research_status §2.9）

DQN 的 TD 场，replay 从"单一关系"到"均匀混合"连续变化 → κ_TD 应随混合度
上升，直接检验"TD 对齐 = 聚合一致性"。

## 2. 闭式预测（镜像带臂机）

常数 obs + 2 动作的镜像 bandit：Q 网络无法区分关系，在混合度 ρ 下收敛到
关系均值 Q0=1−2ρ, Q1=2ρ−1（γ 项在残差中相消，任意 γ 成立）。
关系条件 TD 梯度满足 g_B = −g_A·(1−ρ)/ρ，故：

```
κ_TD(ρ) = (1−2ρ)² / (2(ρ² + (1−ρ)²))     单调下降，ρ=0.5 时精确为 0
```

## 3. 实测（3 seeds，Q 网 1→8→2 MLP，N_train=2000, N_meas=1000）

| ρ | κ_TD γ=0 | 闭式 | κ_TD γ=0.9 | 闭式 |
|---|---|---|---|---|
| 0.00 | 0.5000 ± 0.0000 | 0.5000 | 0.663 ± 0.065 | 0.5000 |
| 0.10 | 0.378 ± 0.017 | 0.3902 | 0.520 ± 0.081 | 0.3902 |
| 0.20 | 0.279 ± 0.019 | 0.2647 | 0.257 ± 0.023 | 0.2647 |
| 0.25 | 0.156 ± 0.032 | 0.2000 | 0.201 ± 0.000 | 0.2000 |
| 0.30 | 0.120 ± 0.015 | 0.1379 | 0.171 ± 0.035 | 0.1379 |
| 0.40 | 0.021 ± 0.011 | 0.0385 | 0.041 ± 0.030 | 0.0385 |
| 0.50 | 0.010 ± 0.007 | 0.0000 | 0.003 ± 0.002 | 0.0000 |

- 单调下降、终点 ρ=0.5 精确塌缩到 0；中间点与闭式吻合（训练不充分处有噪声）。
- **Q 收敛到关系均值**（Q0=1−2ρ 等），均值处 g_A 与 g_B 反平行 → κ=0。

## 4. 解读

1. **"TD 对齐 = 聚合一致性"在镜像 bandit 上不成立**：TD 聚合到均值，但
   **均值处恰恰是梯度精确相消点**——"钝化"不是高 κ，是 κ=0 的塌缩。
2. **与跨环境结果一致**：Overcooked/510K 的 TD 高 κ 依赖**非镜像结构**
   （多状态、非对称关系效应、值传播），不是 TD 目标"按构造聚合"的必然结果。
   E1 的"S>D 反而出现"在此得到闭式解释：TD 场在均值处是 odd 场。
3. **框架修正**：C.0"偶分量幸存"只对**有共享结构**的场成立；镜像 bandit 上
   TD 也是奇场。字段轴的真实载体是 softq 的 α（T2 单调定理）与跨环境场轴。

## 5. 对论文

- E3 从"待跑"变"已判决（阴性）"：作为 §4/负面边界的一部分——
  "TD 对齐需非镜像结构；镜像 bandit 上 value 场同样塌缩（κ→0）"。
- 与 rollou_protocol_artifact.md 一起构成方法学章节的第二个负面证据。
