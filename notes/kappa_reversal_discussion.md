# κ 反转：定义性问题还是真实的行为差异？

> 关于 policy-based 与 value-based 两类算法在 κ（梯度保留率）上的反转现象
> 的讨论笔记。2026-07-31。

## 1. 问题

PG 方法（PPO/A2C/REINFORCE）在隐藏关系信息下 κ 收缩（SINGLE > DYNAMIC），
而 value 方法（DQN）表现为 D > S 的"反转"。这个反转是真实行为差异，
还是指标定义方式导致的必然结果？

## 2. 定义部分：两家"自然"的梯度确实不可比

- PG 梯度是 REINFORCE 场：`g = E[∇log π(a|s)·A]`，在策略参数空间，
  回答"该偏好哪个动作"。
- DQN 梯度是 TD 场：`g = ∇E[(Q(s,a) − y)²]`，在 Q 网络参数空间，
  回答"这个 (s,a) 值多少"。

这是两个不同对象、不同参数空间、不同单位的向量。直接把它们的 κ 并列
比较（0.644 vs 0.797）是不可比的；其中"反转"有一大部分是构造性的——
TD 目标 `y = r + γ max Q` 按定义就是跨关系聚合一致的，所以 TD 场的梯度
天然对齐。

## 3. 但"无法定义相同梯度"是伪命题

完全存在共同测量基：**同一张策略/Q 网络 + 同一批数据，只换目标函数**。

| 目标函数 | 性质 |
|---|---|
| REINFORCE `∇logπ·A` | 硬 mode-seeking |
| AWR `∇logπ·exp(A/τ)` | 插值（TD 一致值 + 优势权重） |
| soft-Q actor `∇Σπ(Q−α logπ)` | 软 mode-seeking |
| DPG `∇_θ Q(s,π(s))` | 经策略参数的 TD 值链式梯度 |
| TD-loss `∇(Q−y)²` | 纯 mean-seeking |

SAC actor/critic 分离就是这个协议：同一网络、同一数据，只有目标不同。
所以问题从来不是"有没有公共梯度"，而是"选哪个梯度场"。

## 4. 真实部分：mode-seeking vs mean-seeking

反转不全是定义产物，因为两者对应**不同的损失几何**，这在数据上是可测的：

- **mode-seeking（分类式）**：优势加权的 `∇log π`，在关系混合数据下，
  不同关系指向不同最优动作 → 梯度异号抵消 → κ→0（Overcooked PPO κ=0.00）。
- **mean-seeking（回归式）**：`(Q−y)²` 的目标是混合期望，聚合后依然良定义
  → 梯度对齐 → κ 高（Overcooked DQN κ=0.64），**但行为不可执行**（reward=0）。

结论：TD 的 κ 高不是鲁棒性，而是同一 aliasing 的症状——Q 把关系平均掉了，
而策略必须做选择。两族都以相反签名失败：**PG 塌缩（脆），value 钝化（钝）**。

## 5. 更锋利的点：PG 内部已经在用 TD 自举

A2C/PPO 的 advantage 是用 GAE（TD 自举）算的。所以两家的差别**不在
"有没有用 TD"**，而在外层目标对什么求梯度：对动作分布取模，还是对值
预测求均值。两者共享同一个 value estimator，只有外目标不同。

数据已给出暗示：离散 SAC actor（对 Q 取 softmax 平均）落在两族中间
（0.542/0.569，几乎持平），符合"软的平均"而非硬 mode-seeking 的预测。

## 6. 决定性实验：插值谱

要证明"不是纯定义"，需要一个连续过渡的证据链：

1. **SAC actor/critic 分离 κ**：actor（PG 式）应 S>D，critic（TD 式）应
   D>S。已有 SAC 模型 checkpoints，只需补 critic 梯度。
2. **AWR**（TD 一致值 + 优势加权）：κ 应落在两族之间。
3. **温度扫描**：softmax 策略 τ 从小到大，κ_actor(τ) 应连续从 PG 式过渡
   到 TD 式，给两族一个统一刻度。
4. **replay 混合消融**（DQN）：单一关系数据 vs 均匀混合，κ_TD 应随混合度
   上升，直接检验"调和机制"。

若这些插值确实连续，则证明反转 = 目标函数几何的连续谱，而非纯定义。

## 7. 对论文的意义

- 反转不是意外，而是 **κ 是梯度场的函数**，梯度场的选择由目标函数的
  模式/均值性质决定。给定目标性质可以预测 κ 的方向。
- 不要宣称"value 方法免疫/鲁棒"（假），而是"κ 必须与 reward 和能量门
  联合解读：κ_TD 高 + reward 低 = 聚合正确、行动无用"。
- κ 与 reward 是两条轴：κ 诊断训练健康，受控 reward 落差（OBVIOUS vs
  DYNAMIC）度量行为抵抗。两者联合才有意义。
