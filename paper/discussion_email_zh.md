# 讨论稿附言（可直接粘贴到邮件或消息里）

附件是我们下一篇论文的讨论稿 `main_discussion.pdf`（11 页，ICLR 2027 官方
样式）。这一版是在修正了测量口径之后重写的，和之前那份草稿有实质差别，
所以想先请大家帮我挑问题，再决定投不投、怎么投。

## 这一版和旧稿的区别

1. **主线压缩成一个命题。** 从"六个发现"改成一句话：隐藏条件被平均时，
   剩什么不只由对称性决定，还由混合分布的几何与目标诱导的场结构决定；
   贡献按"结构 / 测量 / 边界"三部分组织。
2. **统一了指标定义。** 主指标改为有界的 mixture-reference 保留率
   `kappa_mix = ||Σ p_i g_i||² / Σ p_i ||g_i||²`，此前的均匀参照口径只用于
   读旧数据。
3. **区分了结构分数与噪声分数。** 旧稿里"reinforce 死了（κ≈0.015）"实际
   是被单集噪声 `kappa_ep` 主导的读数；按结构分数，真实环境里策略梯度场
   约 0.51、价值场约 0.95–0.998，差距约 1.9 倍而不是 30–65 倍；带可微基线
   的优势场在 Overcooked 切换下约 0.59，只比普通策略梯度略高、仍远低于
   价值场。Toy 镜像模型上的精确相消不变，hidden/revealed 对比改为同一策略、
   同参数、同 seed 的受控实验。
4. **撤回了几条站不住的结论。** 不再说方向依赖是 S3/非交换群特有（实验
   显示 K≥3 就有）；不再说 softq 会"峰化自噬"（按实现的损失方向，梯度下降
   是趋向均匀）；Fisher/KL 只作为单独变体并限定参数空间。
5. **补了配对测量。** 510K 的两个梯度场现在来自同一 episode 批次（旧数据
   是两批分开采样）；Overcooked 也改成每个 checkpoint 一个共享 episode
   批次，并把 `awr` 从 detached 标准化优势改成正文定义的可微基线场后重跑
   （dynamic 0.590）；期间修掉一个 `[T]` 与 `[T,1]` 广播的形状 bug（首轮
   错值 0.854 已作废），权重改为 float64 并核验下溢（旧 float32 下最多
   78% 的 step 权重会静默归零，修正后分数与修正版差异 < 1.5e-7），梯度
   统一零填充到完整参数空间。
6. **新增真实三群体实验（DICES-350）。** 350 个对话、123 名评审者全部
   重复评价，用 race/age/gender 作隐藏条件。race 轴 `kappa_mix=0.156`，
   但对比能量被 item 噪声淹没（0.0019 vs 0.0114），条件化模型没有带来
   平均或最差组提升——审计正确预测"这不是容量问题"，与 Toy 容量实验
   （对比能量占优时条件化把最差条件从 0.003 提到 1.97）形成两端对照。

## 希望重点反馈的问题（文末也列了同样几条）

1. "结构 / 测量 / 边界"三部分的主线是否成立？还是应该把 K 路几何单独提成
   头条贡献？
2. 新的 DICES-350 是**阴性**容量结果（条件化模型没有提升最差组）：把它写成
   "审计正确预测不需要干预"的佐证，还是会被读成论文变弱？要不要补第二个
   数据集和 group-DRO / 重加权基线？
3. 1.9 倍的结构差距这样报是否合理？还是应该保留噪声口径的对比？
4. 真实环境证据仍偏支撑性（Overcooked 3 seeds、510K 关系驱动弱）。优先补
   哪个环境？
5. 有没有我们漏掉的相关工作（结构性相消 / 隐藏条件下的目标依赖梯度保留）？
6. "保留率不是性能分数"这个边界要不要留在 abstract？会不会引来"那我为什么
   要关心 κ"的质疑？
