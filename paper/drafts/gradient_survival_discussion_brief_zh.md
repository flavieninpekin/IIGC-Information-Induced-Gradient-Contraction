# 隐藏多条件异质性下的梯度幸存

> 交流初稿，不是定稿论文。目的：把当前 IIGC 后续工作整理成一页可被同行
> 质疑和改写的研究提案。最后更新：2026-08-28。

## 1. 一句话问题

当训练数据来自多个隐藏条件，而不同条件要求不同的行为或目标时，共享模型实际
收到的是条件梯度的混合：

```text
g_mix = sum_i p_i g_i
```

我们想回答：

> 混合梯度损失了什么？这种损失能否由条件梯度的几何结构提前预测，并指导
> 选择共享模型、条件化容量或分组训练？

这项工作承接 AAAI 中的 IIGC 现象，但不再把问题表述为“PG 优于或劣于 value”，
也不把 κ 当成训练成功的充分预测器。

## 2. 当前最可信的发现

### 2.1 多条件几何

在 K-way matching bandit 中使用精确期望梯度：

- K=2、3、4 的均匀 matching mixture 都使 expq/linear field 精确相消，闭式和
  autograd 误差不超过 `2.22e-16`。
- K=3 首次出现二维混合单纯形，固定到均匀分布的 L1 距离后，κ 随混合方向
  变化约 `2.54x`（使用有界的 mixture-reference κ 时约 `3.08x`）。
- K=4 方向变化仍然存在，说明现象来自多条件几何，不应宣传为 S3 或非交换群
  特有结果。
- softq 的熵通道和条件混合通道可以相消；这一点在 K=2 的非均匀混合中已经
  出现，不是 S3 特有。

脚本和结果：

- `experiments/common_basis/toy/verify_kway_geometry.py`
- `data/kappa/toy_fields/kway_geometry.json`

### 2.2 共享容量与条件化容量

在 K=3 的精确 full-batch 训练中，对比一个共享策略和一个每条件独立 logits 的
条件化策略：

- 均匀 mixture、线性目标：共享策略的混合梯度为零，平均 reward 约 `0.667`；
  条件化策略平均 reward 约 `1.99`。
- mild mixture：共享策略平均 reward 约 `1.20`，但最差条件 reward 接近 `0`；
  条件化策略最差条件约 `1.97`。
- softq 可以提高共享模型的最差条件表现，但同时牺牲平均 reward，体现的是
  Pareto 折衷，而不是简单的“训练失败”。

脚本和结果：

- `experiments/common_basis/toy/run_shared_vs_conditional.py`
- `data/kappa/compromise_training/results.json`
- `notes/kway_compromise_verdict.md`

### 2.3 κ 的适用边界

O4 的 96-run 实验显示：switch-hidden 任务中 TD 的 κ 约为 `0.058`，但 reward
约为 `36.97`，明显优于 κ 更高的 softq。原因是 κ 条件化的变量与任务需要跟踪的
历史变量不一致。

因此当前更准确的结论是：

> κ 描述指定条件梯度在聚合后保留了多少，不直接描述任务性能。要获得训练指导，
> 还必须测量条件是否是任务真正依赖的变量，以及绝对梯度能量和每条件性能。

## 3. 候选核心贡献

暂定表述为：

> 我们给出一个隐藏多条件异质性下的梯度混合分析。该分析说明：均匀条件混合会
> 消除零均值的条件特异方向；当条件数至少为三时，幸存量依赖混合分布的方向，
> 而不是只依赖异质性大小；不同目标通道还可以发生可预测的梯度干涉。基于
> 条件梯度审计，我们区分共享模型的平均目标折衷与需要条件化容量的情形。

这个贡献依赖两个部分同时成立：

1. 理论上给出一般 K 条件的梯度混合和通道干涉公式。
2. 实验上证明审计结果能指导一次具体决策，例如共享模型和条件化 adapter 之间
   的选择，并改善独立条件上的性能或最差组表现。

如果只有第一部分，文章应定位为理论/分析论文；不能称为通用训练 framework。

## 4. 不再主张的内容

- 不主张 value 方法普遍优于 policy-gradient 方法。
- 不主张 κ 低必然意味着训练失败。
- 不主张方向依赖是 S3、非交换性或群论特有现象。
- 不主张 Overcooked 当前 witness 已经证明了 primitive-action policy-gradient
  的收缩；它目前是 option-level 的受控任务构造。
- 不主张 510K 是关系诊断的有效应用环境；现有结果更适合作为关系弱驱动的边界。
- 不主张 softq 在 softmax 参数化下必然 mode-seeking；该说法需要与实际优化符号
  重新核对，暂时删除。

## 5. 必须先修正的技术问题

1. `kappa_uniform_ref` 可能大于 1，需要同时报告有界的 mixture-reference κ。
2. `experiments/common_basis/toy/verify_kl_kappa.py` 的 Fisher 二次型必须保留
   `-(pi @ g)^2` 项；现有 Prop 6 不能直接称为已验证。
3. softq 的干涉点应区分“分子通道抵消点”和“κ 比值的最小点”。
4. S3 实验需要改写成 K-way 几何结果，除非新增真正区分不同群表示的实验。
5. 旧的 `paper/resources/`、`notes/research_status.md` 和当前 draft 仍有过时数字，
   写稿前需要建立一个唯一结果索引。

## 6. 真实数据的最低要求

一个可用的三组异质数据集至少需要：

- 同一类输入或共享 prompt/input 空间；
- 每个样本带有三个以上真实群体、用户、任务或域标签；
- 群体之间存在目标、偏好、决策或标签分布差异，而不只是随机噪声；
- 可以构造 group-conditioned loss/gradient；
- 有独立测试集，能够报告平均性能和最差组性能；
- 许可允许下载、训练和发表聚合结果；
- 最好有用户/annotator/region/task 的原始标签，而不是事后按模型输出聚类。

优先级最高的候选方向是：

1. 三个以上偏好群体对同一 prompt 的 preference 数据；
2. 带身份属性的 toxicity 或 moderation 数据；
3. 多域但任务相同的真实数据，用域作为隐藏条件；
4. coding-agent 轨迹中的解法类型，但这应作为独立后续项目。

当前数据集短名单和许可/混杂分析见 `notes/real_three_group_datasets.md`。第一候选是
DICES-350：350 个对话由 123 名带人口属性的评审者全部重复标注，仓库 README 明确
采用 CC BY 4.0。第二候选是 WVS/WorldValuesBench：同一价值问题由多个真实人口群体
回答，规模更大，但 WVS 原始数据需要注册并接受 non-redistribution 条款。

## 7. 计划中的决定性实验

### Phase A：理论和测量收口

- 完成 K-way 公式和 κ 的两种归一化；
- 修正 Fisher/KL 命题；
- 对 K=2、3、4 做统一的闭式、数值和边界测试；
- 删除所有旧的 S3-only、softq 自噬和 κ 预测行为的表述。

### Phase B：受控训练闭环

- 共享模型、条件化 adapter、分组更新三种方案；
- 同一初始模型、同一数据、同一预算；
- 测平均 reward、最差组 reward、每组 regret、梯度能量和 κ；
- 预先规定何时审计结果推荐条件化容量。

### Phase C：真实三组数据

- 冻结一个小模型，先测 group-conditioned gradients；
- 根据审计选择共享或条件化方案；
- 在独立测试集验证平均和最差组性能；
- 若审计不能改善决策，只保留理论结论，不再称为训练框架。
