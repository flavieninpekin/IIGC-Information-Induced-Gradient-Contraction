# 隐藏群对称异质性下的梯度幸存：精确相消、方向依赖与通道干涉

**草稿 v0.5（中文版，2026-08-26）——用于征求意见。所有数字均来自已验证
实验；数据溯源见附录表。一般群定理的正式证明进行中；Z₂/S₃ 实例已做到
机器精度验证。**

---

## 摘要

训练信号可能在触达权重之前就被静默抹除：当训练数据被一个**隐藏的分类条件**
（队友身份、用户群体、偏好模式）分层，且各条件的目标由一个对称群 G 关联时，
跨条件平均更新会相消掉一切非不变梯度分量。我们在一个最小的三条件（S₃ 对称）
带臂机中研究这种相消的代数结构，得到三个结果：(1) 权重逐元素且参数无关的
目标函数在对称混合下**精确相消**——二条件镜像结果的一般化；(2) **方向依赖**：
固定混合不对称度（到均匀点的 L1 距离相同）时，幸存率随混合分布方向变化最大
相差 2.5 倍——该现象在二条件情形下结构上不可能出现（其参数切空间一维）；
(3) **双通道干涉**：带熵正则的 soft-Q 目标将策略固有通道与混合诱导通道作为
二维空间中的向量相加，两者可相消性干涉，使幸存率关于熵系数非单调，且有精确
闭式。第四个结果关于**结构轴**：目标不对称性救活奇场（策略梯度类），闭式为
(r−s)²/(2(r²+s²))；而值场（TD）在自己收敛的定点处对**任意**不对称度都塌缩。
对多任务学习、联邦学习、偏好学习的含义在文中讨论，包括一个可证伪的警告：
调错的熵正则化会摧毁混合不对称性提供的幸存信号。

## 1. 引言

考虑一个训练数据来自多个子群体的学习系统——偏好冲突的用户、任务结构互为镜像
的联邦客户端、角色被隐藏的队友。当子群体身份**对策略不可见**、但**决定什么行为
才是正确的**时，各子群体条件化梯度的方向可能互相冲突。平均后的更新于是相消：
训练看似缓慢或停滞，但损失曲线上看不出任何异常。

这些冲突何时**精确**相消？何时**部分**幸存？能否在训练**之前**预测幸存率？
本文在一个由对称群 G 控制冲突结构的最小设定中给出代数的回答。

**运行示例。** 一个语言模型在来自异质用户的偏好对数据上微调。三个群体
系统性分歧：群体 A 偏好冗长回答、群体 B 偏好简洁、群体 C 偏好代码风格。
推理时用户身份**不在 prompt 中**——三个群体给出相同输入，而"什么是对的"
因群体而异。训练数据以未知比例 p 混合群体；各群体梯度指向不同方向；
策略实际吃下的是**混合后**的梯度。这正是我们的带臂机所抽象的现象：
条件 = 用户群体，动作 = 回答风格，Q_i(j) = 匹配群体 i 偏好的奖励，常值
观测 = 隐藏身份，混合 p = 群体比例。带臂机的每个成分都对应运行示例的
一个特征，没有什么是任意的。

**为什么是三条件（不是两个）。** 二条件（Z₂）是已充分理解的镜像情形：所有
梯度共线、不对称只有一个方向、幸存是不对称幅度的一元函数（闭式已验证，
§3）。三条件是最小的拥有**二维不可约表示**的设定——这里幸存率可以依赖
混合的**方向**（§3.2）、幸存通道可以**干涉**（§3.3）。这些现象正是本文
的意义所在，二条件模型无法展示它们；Z₂ 结果保留为已验证的基线情形。

**设定（一段话版）。** 一个常值观测的带臂机，动作数 |A| = |G|；条件 g ∈ G
赋予目标值 Q_g；策略 π_θ 是看不到 g 的 softmax。每个目标函数诱导一个条件
条件化期望梯度 g_g = ∇L_g。训练按分布 p 混合条件；有效更新为 ĝ_p = E_p[g_g]。
我们研究**幸存率**

    κ(p) = ‖ĝ_p‖² / E_均匀[‖g_g‖²]，

即混合后幸存的条件化信号能量占比。

**贡献。**
1. **精确相消的一般化。** 逐元素、参数无关权重、对目标线性的目标函数，在
   对称混合下精确相消（κ = 0，到 1e-32），对 G = Z₂ 和 G = S₃ 都成立。
2. **方向依赖（S₃ 新现象）。** 固定混合不对称度，κ 随 p 在混合单纯形中的
   **方向**变化最大 2.5 倍。Z₂ 的切空间一维，不对称只有单一方向——该现象
   在那里结构上不可能出现。
3. **双通道干涉（S₃ 新现象）。** soft-Q 目标有两个幸存通道——策略固有的熵
   通道与混合诱导通道。二者在二维切空间中矢量相加，可相互对消；κ(α) 非单调
   且有精确闭式。实践警告：熵正则化可能抹掉本已幸存的信号。
4. **结构轴按场类型分裂。** 目标不对称救活策略梯度场（精确闭式），但 TD/值场
   在自己收敛定点处对所有不对称度都塌缩（残差反对称 e_B = −e_A）。

## 2. 设定与定义

**三条件匹配带臂机。** 条件 i ∈ {0,1,2}；动作 j ∈ {0,1,2}；Q_i(j) = 2R·[j=i]。
条件隐藏：观测为常值，π_θ = softmax(z)。所有期望对 a∼π_θ 取（规范的 π 加权
协议；已知确定性 rollout 会污染此类测量 [协议伪影 note]）。

**场。** 采用*期望逐样本*定义下的条件条件化梯度（与我们的测量代码一致）：
- expq / reinforce：权重 w = Q（参数无关、逐元素）；
- softq：L = Σ_a π_a (α log π_a − Q_g(a))——熵通道 + Q 通道；
- awr：w = exp((Q−V)/τ)，V 可导（baseline 通道）。

**混合。** p ∈ Δ² 是隐藏条件的训练分布。
κ(p) := ‖Σ_i p_i g_i‖² / E_i‖g_i‖²（均匀参考能量）。

## 3. 理论

### 3.1 精确相消（奇场）

**命题 1。** 对任何满足 g_i = ∇⟨π, Q_i⟩、且 Q_i 逐元素参数无关的场（reinforce、
expq、无 baseline 的 awr、softmax(Q/τ) 权重），均匀混合精确相消：ĝ = 0，κ = 0。

*验证（机器精度）：* G=Z₂ 与 G=S₃，κ ≈ 1e-32（3 seeds，全部场）。
*证明草图（Z₂）：* Q_B = swap(Q_A) ⟹ g_B = −g_A。*（S₃）：* Q_i = 2R·e_i 且
⟨π,Q_i⟩ = 2R π_i；Σ_i (1/3)∇⟨π,Q_i⟩ = (2R/3)∇Σ_i π_i = 0，因为 Σ_i π_i = 1。
S₃ 的机制与 Z₂ **不同**（是一组梯度之和因 Σπ=1 而消失，而非成对镜像）——
两者都精确。

### 3.2 闭式与方向依赖（奇场）

**命题 2。** S₃ 带臂机中 expq/reinforce：
    ĝ_p[j] = 2R π_j (p_j − ⟨p,π⟩)，
    κ(p,π) = Σ_j π_j² (p_j − ⟨p,π⟩)² / E_i Σ_j π_j² (δ_ij − π_i)²。
*验证：* 闭式 vs autograd，200 组随机 (z,p) 最大绝对误差 6.3e-15。

**方向依赖。** 固定到均匀混合的 L1 距离、绕 24 个方向旋转 p：距离 0.45 时
κ ∈ [0.075, 0.192]——仅由方向决定的 2.5 倍差异。Z₂ 的混合单纯形是线段：
不对称没有方向，幸存只随幅度变化。方向依赖的出现是二维切空间的必然结果，
也是该框架确实群论化（而非 Z₂ 的换皮复述）的经验签名。

### 3.3 双通道干涉（softq）

**命题 3。** softq 的条件梯度与混合梯度：
    g_i[j] = π_j [ α(ℓ_j − ℓ̄) − 2R(δ_ij − π_i) ]，ℓ = log π，ℓ̄ = ⟨π,ℓ⟩
    ĝ_p[j] = π_j [ α(ℓ_j − ℓ̄) − 2R(p_j − ⟨p,π⟩) ]，
    κ_softq = Σ_j π_j² [α(ℓ_j−ℓ̄) − 2R(p_j−⟨p,π⟩)]²
              / mean_i Σ_j π_j² [α(ℓ_j−ℓ̄) − 2R(δ_ij−π_i)]²。

两个方括号即*熵通道*（方向 ℓ−ℓ̄，策略固有）与*混合通道*（方向 p−⟨p,π⟩，
数据诱导）。二者处于同一二维切空间，作为向量相加。

**非单调性。** p = (0.7, 0.2, 0.1) 时 κ(α) = 0.396（α=0.05）→ 0.032（α=2）
→ 0.415（α=5）：中间 α 处两通道相消性对齐。*验证：* 闭式 vs autograd，
最大绝对误差 3.3e-16。

**可检验的警告。** 对任意不对称 p 与固定策略，存在使 κ 塌缩的破坏性 α*。
在偏好学习（RLHF/DPO）中熵/KL 系数是超参——这意味着正则化强度可以静默
抹掉混合不对称性提供的信号。这是一个可证伪、可行动的预测。

### 3.4 结构轴：场类型分裂

**命题 4。** 二条件非对称带臂机 Q_A=(r,−r)、Q_B=(−s,+s)，均匀混合：
- 奇场（expq/reinforce）：κ = (r−s)² / (2(r²+s²))——被不对称救活；
  验证到 1.4e-17。
- TD 场在收敛定点：对**一切** s/r 有残差反对称 e_B = −e_A ⟹ κ_TD → 0；
  实测 s/r ∈ {1.0…0.0} 全为 0.001 ± 0.001，而 s/r=0 时 expq 为 0.5。

解读：**结构轴是场类型依赖的**。结构不对称恰好救活被对称设计杀死的场，
而值场死于自己的收敛——这是动态机制，不是结构机制。

### 3.5 吸引子结构（动力学；已验证，理论见笔记）

单步几何不决定训练去向。对称混合下三类场有不同吸引子（梯度流模拟 +
数值差分验证）：
- **奇场被冻结**：梯度恒零，策略永不离开初始化——"卡死"是精确的，
  不是渐近的。
- **softq 只靠熵通道幸存**；softmax 参数化下该通道是 **mode-seeking**——
  流把 π 推向峰化（对称破缺吸引子），吃掉自己制造的锐度。（"熵流推向
  均匀"的 π-空间直觉在 softmax 重参数化下不成立。）
- **TD 收敛到关系均值值函数**（G-不变），诱导策略（Q̄ 的 argmax/softmax）
  退化为均匀。

解读：*幸存是单步性质；幸存者可能在定点处自噬（softq）或失效（TD）。*
这与结构轴结果闭环：值场在定点塌缩（§3.4）是同一吸引子的静态面孔。

### 3.6 一般群猜想（开放）

我们猜想一般陈述：对称混合下，平均梯度只含 G 诱导表示的不变分量；幸存率
按不可约表示分解且有闭式系数；二维不可约表示催生方向依赖与干涉。Z₂ 与 S₃
是已验证的实例。一般证明进行中。

### 3.7 KL 形式化（机器精度验证）

κ 的欧氏定义掩盖了一个度量事实：softmax 参数化下，κ 是**Fisher 度量比**，
而 Fisher 是 KL 的二阶展开。对切空间梯度（Σ_b g_b = 0；我们场还满足
πᵀg = 0）：

**命题 6（κ 为无穷小 KL 比）。**
    κ_F(p) = (ĝᵀFĝ) / E_r[g_rᵀFg_r] = Σ_b π_b ĝ_b² / E_r[Σ_b π_b g_{r,b}²]
           = lim_{ε→0} KL(π ‖ π+εĝ) / E_r[KL(π ‖ π+εg_r)]，
F = diag(π) − ππᵀ 为 categorical Fisher 度量。*证明：* πᵀg = 0 ⟹ 切空间上
Fg = diag(π)g；KL(π‖π+εg) = (ε²/2)gᵀFg + O(ε³)。∎
*验证：* ε 收缩序列收敛到 κ_F（float64 下限）。

**命题 9（KL 投影从 hidden mixture 推导而来，非假设）。**
softq 目标在隐藏条件下：

    L_r = α·KL(π ‖ π_r*) + const，      π_r*(a) ∝ exp(Q_r(a)/α)
    Σ_r p_r L_r = α·KL(π ‖ π̃) + const，  π̃(a) ∝ exp(Σ_r p_r Q_r(a)/α)
    ⟹  ĝ_p = α·∇KL(π ‖ softmax(Q̄_p/α))，  Q̄_p := Σ_r p_r Q_r。

第一行说明每个条件的 softq 目标**就是**到该条件最优策略的反向 KL
（α·KL(π‖π_r*) = αΣπ logπ − ⟨π,Q_r⟩ + const）。第二行是加权混合勾股
恒等式（命题 7）。故混合算子 = 到**混合平均价值**的几何平均投影：
幸存方向 = Q̄_p 在价值空间的方向。

*推论（镜像）。* 镜像条件 + 均匀混合 ⟹ Q̄_p = 0、π̃ = 均匀、
ĝ = α·π_b(ℓ_b−ℓ̄)——§3.3 的熵通道**由推导得出**而非假设；Q 线性（奇）场
是 α→0 的退化极限、无 KL 目标，恢复精确相消。
*验证（机器精度）：* 每条件等式 5.6e-16；混合梯度 vs 投影 5.0e-16；
镜像端到端精确；非对称链 3.1e-16（`verify_mixture_to_kl.py`）。

**命题 7（混合 = 几何平均投影；KL 勾股恒等式）。**
对反向 KL 蒸馏场 g_r = ∇KL(π‖π_r*)（log 比值权重）：
    ĝ_p = Σ_r p_r g_r = ∇KL(π ‖ π̃)，  π̃(a) ∝ exp(Σ_r p_r log π_r*(a))。
*证明：* Σ_r p_r KL(π‖π_r*) = KL(π‖π̃) + const（加权混合恒等式；归一化
常数与 π 无关）。*推论：* 镜像/置换目标 + 均匀混合 ⟹ π̃ = 均匀，幸存混合
梯度精确等于 §3.3 的熵通道 π_b(ℓ_b−ℓ̄)——"偶分量"在 KL 术语下即"到均匀
目标的反向 KL"。*验证：* 3.3e-16。

**命题 8（KL 方向轴 = 场轴）。** 模式/均值寻求（变分推断的经典
exclusive/inclusive KL 二分）给场分类：log 比值（蒸馏）权重 = 反向 KL
（模式寻求；幸存后自噬）；前向 KL 场 g_r = π − π_r* = 均值寻求，混合梯度
= π − π̄（算术平均；对齐但退化）；Q 线性场无 KL 目标（精确相消）。
验证：前向 KL 混合恒等式 0.00e+00；镜像闭式 κ_F = 0.7838 精确。

解读：最初的"模式/均值几何"直觉（对梯度保留）现在有了精确陈述——场的权重
向哪个 KL 方向蒸馏。这在偏好学习中可直接检验：DPO 类目标就是偏好组上的
反向 KL 目标。

## 5. 含义与相关工作

**多任务学习。** 梯度冲突文献（PCGrad、CAGrad、Nash-MTL 等）把冲突当作待
缓解的经验量。我们刻画冲突何时**结构性不可避免**——这是有原则的缓解的
前提。

**联邦学习。** drift 分析用梯度相异性假设给异质性效应定界；Wang et al.
(2022) 证明朴素度量高估危害。我们的分解给出结构规则：对称镜像客户端精确
相消，非对称混合按方向幸存。

**损失对称化（最近邻）。** 标签噪声文献（unhinged loss；ICLR 2025
Symmetrization of Losses）工作在**风险空间**：对称损失在随机标签翻转下
保持风险最小子不变。我们工作在**梯度空间**、面对**结构化**异质性（真实
子群体而非噪声）：幸存率、方向依赖、干涉是他们的风险空间理论没有的对象。
（随机噪声 vs 结构化目标；风险最优 vs 梯度幸存——这两组区分必须在文中
显式声明。）

**偏好学习（RLHF）。** 2026 年已有工作记录偏好平均如何使少数群体被低估
（程序公平性）并提出经验缓解。我们的理论补上代数层：对称偏好组使
DPO/BCE 梯度精确相消；不对称按方向幸存；熵系数可破坏性干涉。一个可直接
检验的实验随之而来：调 β 前后测偏好组条件化梯度上的 κ。

**行为解耦（边界）。** 伴随实验中，当任务需求（从奖励历史跟踪切换条件）
与所测关系变量正交时，干净基 κ 不预测任务成败——诊断告诉你梯度保留，
不告诉你命运。

**经验来源（可选引用）。** 隐藏关系变量在实践中会相消策略梯度这一点，
最早在多智能体游戏（隐藏队友分配、隐藏角色）中经验性地观察到。本文
自足，任何结果都不依赖该工作；当该观察公开可查（arXiv / AAAI 2027）后，
可作为经验动机在此引用。

## 6. 局限

- 玩具常值观测带臂机；真实数据（偏好数据）演示是自然的下一步，尚未包含。
- 精确陈述限于对称混合与逐元素权重场；一般群为猜想而非定理。
- TD 塌缩陈述是渐近的（收敛定点处）；训练中的暂态动力学待刻画。

## 7. 结论

在隐藏群对称异质性下，梯度幸存不是经验偶然，而是可计算的代数量：奇场精确
相消、≥2 维切空间中的方向依赖幸存、幸存通道间的破坏性干涉。该框架把
"为什么我的训练停滞"变成闭式问题，并给出至少一条可行动的实践警告。
