## 一句话主线

> **隐藏关系信息下，梯度场按权重函数的奇偶几何在"保留信号"与"保留关系特异性"
> 之间权衡：硬策略梯度场收缩（信号相消，κ→0），值/软场对齐（关系不可见，κ→1）。**
> "PG-vs-value 反转"是这个权衡的可预测位置，不是算法族优劣——
> 在共同测量基上（同一网络、同一数据、只换目标函数），三环境一致复现。

## 核心结论（正式版）— 保留—特异权衡

> **隐藏关系信息在单一共享观测下，无法同时保留"学习信号"与"关系特异性"。**
> 梯度场按目标函数权重对关系的**奇偶几何**在此权衡上定位：
> **奇场（硬策略梯度）保留特异性、丢失信号**（关系异号梯度相消 → κ→0）；
> **偶场（值/软均值场）保留信号、丢失特异性**（关系对其不可见 → κ→1）。
> "PG-vs-value 反转"不是算法族优劣，而是这个权衡的位置——可用奇偶性预测。

**精确表述**（对应每个子句的证据）：

| 子句 | 证据 | 出处 |
|---|---|---|
| 奇场保留特异性、信号相消 | Toy 精确：reinforce/expq κ=0（g_B=−g_A）；Overcooked/510K 场轴 reinforce 低 | `theory_toy.json`、`oc_field_axis.json`、`510k_field_axis.json` |
| 偶场保留信号、丢失特异性（盲） | value 场 κ 0.94-1.0、E_contrast≈0；witness hidden-obs 恒等 True | `witness_field_axis.json`、`conflict_witnesses.json` |
| 反转=场的属性非算法族 | 三环境同一网络/数据只换目标 → value≫reinforce；复现 A2C vs DQN 反转 | `oc_field_axis.json`、`510k_field_axis.json`、`kappa_summary.json` |
| 机制=奇偶分解 | Toy 闭式：softq κ(α)、softmax(Q/τ) κ(τ) 单调 ✓ | `theory_toy.json` |

**这句话的贡献定位**：它不是"value 更好"也不是"PG 更差"，而是**信息论式的
no-free-lunch**——把上一篇（AAAI 2027）Prop 4"κ 依赖估计器"的开放问题，从"反转
是边界"升级为"**位置可由权重函数几何预测**"。这是机制，不是描述。

**诚实边界（必须写，否则被捶）**：
1. **"盲"不必然有害**：静态评估里 value 方法照样学得好（dynamic reward~120）。
   权衡的**性能后果**只在**关系自适应任务**上体现（部署时关系变化、需按关系切换
   行为）——这条尚未做实验，是开放项 O4。
2. **冲突分层**：witness 上 option 级冲突可证（Q 干净）、原始动作级 Q 平坦——
   "特异性"存在于哪个层级取决于状态与续接（`overcooked_slice.md` §5）。
3. **"无法分离"不指性能缺陷**：value 场从未编码关系（盲），不是"合并了冲突"。

## 核心主张（按强度排序）

1. **场轴效应（三环境一致，主证据）**：同一网络/数据，只换目标函数，
   value 场 κ 显著高于 reinforce 场 κ。
   - Toy 隐藏：0.00 → 0.90（精确闭式，解析锚点）
   - Overcooked dynamic：0.29 → 1.00；static：0.30 → 0.57（κ_mean，n=3）
   - 510K p=0：0.55 → 0.97；p=1：0.46 → 0.98（κ_mean，n=6）
   - 复现上一篇 A2C(0.52) vs DQN(0.92) dynamic 反转（`kappa_summary.json`）
2. **机制（Toy 精确）**：权重函数的奇偶分解——奇场（reinforce/expq）在关系镜像下
   精确相消 κ=0；偶/混合场（softmax(Q/τ)、softq+熵）幸存 κ→1。闭式验证：
   softq κ(α) 单调 0→1 ✓；softmax(Q/τ) κ(τ) 单调 ✓。
3. **Overcooked 受控切片（witness 机制验证，新增）**：在固定状态下用脚本化
   Q 证明 chef/waiter 的最优行为确实不同（24/52 构造状态，margin 干净），
   hidden obs 跨角色恒等 = True，且 value 场在这些冲突状态上对齐
   （κ≈0.94）。——把"关系冲突"从语义推断升级为可机械验证的因果对照，
   回应"贡献不够突出"。见 `paper/resources/overcooked_slice.md`。
4. **测量伪影（方法学注意事项，非主故事）**：固定伙伴协议会关闭角色切换 →
   切换型策略 OOD → 0 奖励 → κ=0 是伪影；需切换保持协议区分"真收缩 vs 伪影"。

## 明确不主张（避免过度承诺）

- ❌ "关系越隐藏，场轴差距越大"——510K 的 p 依赖方向相反/不显著（见下），
  此主张数据不支持，**删**。
- ❌ "reinforce 场在真实环境 κ=0"——κ_ep 里噪声主导确实≈0，但 κ_mean 里
  reinforce 是中等（0.29-0.55）非零；精确相消只在对称 bandit（Toy 均匀 π）成立。
- ⚠️ κ_ep vs κ_mean 是两回事：κ_mean（无噪声，理论预测量）用于场轴主张；
  κ_ep（每集噪声）用于"σ² 主导、仪器不灵敏"的独立观察。

## 510K p 依赖的诚实读法（如保留）

κ_mean（value 场）：p=0: 0.971±0.011，p=0.5: 0.969*，p=1: 0.983±0.004——
三档几乎持平；reinforce 场 p=0: 0.550, p=1: 0.464（n=6，方向与 Overcooked 相反）。
**结论：510K 上"隐藏 vs 可见"的场轴差距基本不变**（0.42-0.52），不支持
"隐藏加强"；本篇只用 510K 证明场轴效应（value>>reinforce），不用它证明隐藏趋势。
